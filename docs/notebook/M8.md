## 2026-10-25T22:26-0700 — decision: wording the design left to the builder
- The flow is its own `## Catching up from order pages` section after "Getting the
  export" (it is not a way to get an export), in the numbered style of "With a browser".
- The real `add` waits for the user's agreement after the dry run, as import does in the
  same file. An empty `orders` list goes straight to `add` (it saves no order, only
  `checked`).
- A cancelled order gets `Cancelled`, the word the export writes; the design names only
  in-flight and delivered. Any undelivered shipment makes the order `In progress`, as
  the export's status is order-level.
- Amounts go in with no `$`: `model.money` leaves "$12.99" as it is and `add` then
  refuses it (read in `saved._amount`), so the steps say so.
- The list's default "past 3 months" filter: when `as_of` is older, tell the user and ask
  before changing it. How the filter is changed was not observed, so the steps don't
  describe it.
- Known-ID check uses `--store amazon`, so an ID shape shared with another store can't
  exit 2.
